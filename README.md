# MeshCore K230

An independent feasibility project for running MeshCore on the LILYGO T-Display K230 as a standalone LoRa messenger. The long-term target is on-device messaging with an existing MeshCore node, without a phone or internet connection.

Phase 1 is a source-first evaluation before buying hardware. Start with the [feasibility plan](docs/feasibility.md), [hardware audit](docs/hardware.md), and [architecture options](docs/architecture.md). Follow the work in [GitHub Issues](https://github.com/traft00/meshcore-k230/issues).
